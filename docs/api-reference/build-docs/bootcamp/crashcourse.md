# Bootcamp — Crash course

**Goal:** install → first skill in 15 minutes.

```bash
git clone https://github.com/theangelofwill/-CLRTY.git && cd -CLRTY
cargo build -p clarity-cli
./target/debug/clrty id calibrate demo
./target/debug/clrty nano run N05 --dry-run
./target/debug/clrty skill run attestation-verify --account=demo
```
